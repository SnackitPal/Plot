Design System & Scientific Architecture

Auditable design tokens and data integrity rules implemented in this prototype.

1. ACCESSIBLE OKABE-ITO PALETTE

Each MCQ option uses colorblind-safe qualitative values paired with geometric glyphs (●, ▲, ■, ◆) and hatching patterns so data never relies on color alone (WCAG 1.4.1).

2. MENG'S BIG DATA DEFECT DEFENSE

Raw non-probability samples inflate false precision ($\rho_{R,Y} \neq 0$). The UI explicitly states Credibility Intervals rather than standard Margin of Error, following AAPOR ethics codes.

3. EQUAL-AREA HEX CARTOGRAM

Eliminates the "Land Doesn't Vote" distortion where massive rural areas visually dominate dense urban populations. Every reporting territory receives equal visual weight.

4. BAYESIAN SHRINKAGE ($k \ge 30$)

Cell counts with $n < 30$ are hatched out ("Insufficient Data") and shrunk to parent regional priors to prevent wild 100% or 0% statistical noise spikes.
